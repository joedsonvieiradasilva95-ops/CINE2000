# CINE 2000 — Documentação inicial

## Contextualização
Locadora fictícia de filmes dos anos 2000.

## Problema
Organizar, relacionar e consultar as informações da locadora com maior confiabilidade.

## Objetivo
Desenvolver um sistema de gerenciamento de dados para organizar, armazenar, consultar e analisar informações da locadora.

## Escopo
Clientes, filmes, categorias, exemplares, locações e consultas/indicadores.

## Tecnologias
HTML, CSS, JavaScript, PostgreSQL, Supabase e Git/GitHub.
