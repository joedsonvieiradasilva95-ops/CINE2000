# Regras de negócio

- RN01 — Cliente precisa estar cadastrado para realizar locação.
- RN02 — Filme pertence a uma categoria.
- RN03 — Filme pode possuir vários exemplares.
- RN04 — Exemplar não pode estar em duas locações ativas.
- RN05 — Cliente inativo não realiza nova locação.
- RN06 — Locações permanecem no histórico.
